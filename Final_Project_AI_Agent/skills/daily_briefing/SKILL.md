# Daily Briefing Skill (example FORMAT only)

## When to use
When the user requests a summary of assignments and events.

## Procedure
1. Retrieve the student's saved preferences.
2. Gather assignments and calendar events using authorized tools.
3. Identify deadlines and potential conflicts.
4. Give a brief, source-labeled plan. Do not invent calendar details.
